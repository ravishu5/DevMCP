## Why Apache-2.0

This project analyses other projects' licences for a living, so its own choice should be
the one it would recommend: permissive, with an explicit patent grant, and unambiguous
about attribution. Apache-2.0 is what this server classifies as `permissive` /
`DIRECT_REUSE` for essentially every consumer.

## A note on what this software produces

This server reports licence information about **third-party repositories**. Those reports:

* are **advisory only and not legal advice** — every licence verdict this software emits
  carries that disclaimer, and it is not decoration;
* describe the licence of the *analysed* repository, which is entirely independent of this
  software's own licence;
* may be wrong. Licence detection is heuristic. Confirm terms with the upstream project and
  with qualified counsel before reusing anyone's code.

Using this software does not grant you any rights to the repositories it analyses. If you
reuse code that this server surfaces, you take on that code's licence obligations, not this
one's.
